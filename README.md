# LBX Technologies website

Source for lbxtechnologies.com, served by GitHub Pages from the `main` branch.

Plain HTML and CSS — no build step.

- `index.html`, `about.html`, `services.html`, `industries.html`, `contact.html` — site pages
- `styles.css` — all styling
- `script.js` — mobile menu toggle
- `thanks.html` — shown after the contact form is sent
- `404.html` — page-not-found
- `services-1.html` — redirect from the old Squarespace Services address

Contact forms post to FormSubmit (formsubmit.co), which emails Luke@LBXtechnologies.com.
The first submission triggers a one-time activation email that must be confirmed.
